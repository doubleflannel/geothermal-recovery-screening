# Contact And Citation

This is a preliminary research-progress packet from an independent researcher. It is shared to make the evidence chain visible, support technical review, and make narrow data/metadata requests easier to evaluate.

## Reuse Boundary

Unless otherwise stated, all rights are reserved.

This packet is not released under a permissive open-source code license at this stage. Please contact the author before reusing text, figures, tables, screenshots, derived analysis, or claim wording from this repository.

This is a practical reuse request, not legal advice. The purpose is to avoid confusion while this work is still being prepared for possible abstract, preprint, or paper submission.

## Citation / Reference Language

If you need to refer to this packet before a formal citation exists, use wording like:

> Pu, I. Preliminary public-data geothermal thermal-recovery screening packet. Public GitHub repository, accessed YYYY-MM-DD.

If you want to reuse or build directly on the figures, text, or derived permeability analysis, please contact me first so the citation, authorship, and claim boundary can be handled correctly.

## What Is Safe To Share

It is fine to share the repository link for technical review, dataset-curation discussion, or source-metadata requests.

When sharing, please describe it as:

- a preliminary public-data screening packet;
- a source-discipline and metadata-request artifact;
- a worked example plus request rationale;
- not a peer-reviewed paper;
- not a broad validation claim.

## What Not To Imply

Please do not describe this packet as proving that all public geothermal datasets can support permeability estimates.

Please do not describe the Utah FORGE August 2025 candidate as a permeability result. In this packet, FORGE August 2025 is explicitly labeled `source-request-needed` because the row-level pressure-flow-temperature forcing file has not been located in the public package inspected.
